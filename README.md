# bark
one of a series of little projects I'm making to learn how to write in C \
bark is supposed to be a simple clone of the `cat` linux command  \
(it's the most incomplete program you've probably ever seen) 

## important
this tool is a work in progress, it's definitely not in a usable state right now so it should only be used as a learning tool (not that there's much to learn from a shitty project like this)

# Current features
- printing to stdout
- being able to concatenate files to print to stdout
